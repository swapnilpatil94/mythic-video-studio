# Prompt — Quality Reviewer

Review the production package before rendering.

Reject if:
- the hook is weak
- source claims are unsupported or misleading
- a sacred figure is treated casually/comically
- the same static frame dominates without narrative purpose
- visual beats merely repeat the narration
- asset requirements are wasteful
- timing is impossible
- text is too long for mobile

Return:
PASS / REVISE
and a prioritized list of fixes.

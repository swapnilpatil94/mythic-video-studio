# Prompt — Visual Director

Convert the approved narration into visual beats.

Target:
- Short: 10–25 beats for 60–90s
- Long: 120–180 beats for 8–12 min

Do NOT request one new AI image per beat.

For each beat specify:
- beat_id
- duration
- narration span
- visual role
- asset references
- whether a new asset is actually required
- camera movement
- animation/reveal
- typography
- transition
- SFX cue
- emotional purpose

Prefer reuse, crops, pans, zooms, layer animation and procedural graphics before requesting new artwork.

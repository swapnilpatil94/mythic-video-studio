# Prompt — Character Director

Create a production-ready character bible from the story package.

For each character provide:
- stable character_id
- canonical/source role
- visual importance
- age representation
- body/build
- clothing
- hair/head details
- ornaments/props
- palette
- expression range
- required poses
- forbidden traits
- image-generation prompt
- mythology-respect rules

Important:
Revered mythological figures must be dignified, non-comedic and visually consistent. Do not add arbitrary fantasy armor, modern clothing, meme expressions or distorted anatomy unless the source/story style explicitly requires them.

Generic characters can be generated freely within the style bible.

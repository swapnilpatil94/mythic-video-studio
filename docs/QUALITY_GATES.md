# Quality Gates

A stage does not pass because the file exists. It passes only when the output is usable.

## Gate 0 — Story
- clear hook within first seconds
- factual/source claims are traceable
- no invented canon presented as fact
- emotional arc has tension and payoff
- ending is satisfying

## Gate 1 — Characters
- identity remains visually consistent
- required poses/expressions exist
- sacred figures are treated respectfully
- no accidental comedic or distorted depiction

## Gate 2 — Visuals
- no static slideshow feel
- meaningful visual change every few seconds
- camera motion supports narration
- typography is legible on mobile
- generated art matches style bible

## Gate 3 — Audio
- Hindi pronunciation is understandable
- narration pacing matches visual beats
- music stays under narration
- SFX are sparse and purposeful

## Gate 4 — Render
- correct aspect ratio
- no missing assets
- no black frames
- no broken text
- audio/video duration alignment within tolerance
- output is playable

## Gate 5 — Human approval
The first production milestone requires manual review before publishing. Automation should reduce repetitive work, not remove editorial judgment.

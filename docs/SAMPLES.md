# Samples & Visual References

This file tracks the visual targets and prototypes used to judge the production system.

## Reference target A — premium illustrated mythology

**Target:** detailed Indian ink-and-wash illustration on parchment/cream, restrained gold/red, strong silhouette, dignified mythological figures, cinematic framing.

**Required:** the final generated artwork should feel like an illustrated storybook brought to life, not a generic AI thumbnail.

## Prototype A — procedural Karna Short

The repository contains the first procedural Karna concept as a technical proof of motion, typography and beat timing.

It is a **pipeline prototype**, not the final visual-quality target.

## Prototype B — realistic procedural Karna

A more detailed procedural character test established that a code-only renderer can produce coherent motion and composition, but the final system should use generated master artwork for substantially higher visual quality.

## Reference target B — generated Karna concept art

The previously generated Karna concept established the desired direction:

- parchment background
- black ink illustration
- detailed armor
- restrained gold
- Indian mythological visual language
- strong Hindi title treatment

Important: image-generation prototypes are references only. The production pipeline must regenerate project-specific artwork rather than hard-code one image.

## Samples to add later

When the user uploads approved reference images/videos, add them under a clearly named project/reference folder and record:

- source
- purpose
- what visual property is being copied
- what must **not** be copied
- whether it is style reference, composition reference, animation reference, or quality reference

## Quality rule

Samples are used to define the target, not to force every story into the same composition. New stories may require new characters, environments, props and visual grammar.
